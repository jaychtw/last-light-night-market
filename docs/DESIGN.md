# Last Light pilot design and implementation brief

Build the accepted one-stall, one-puzzle concept for review in jaychtw/last-light-night-market. Completion means the board, sink and tray are lit simultaneously. A wide and narrow lamp each cycle through three stops. A suspended menu physically interrupts one narrow aim. Orbit changes perspective while preserving lamp aim. The vendor hangs a dishcloth and lowers the shutter on completion. Offer replay, English and Traditional Chinese, tap, drag and keyboard controls. No timer, score or paid services.

Use an original procedural stall, local Three.js dependencies, Diorama orbit and named frozen frames. Test readability from desktop and phone sizes, the orbit clue, and repeatable closing poses. Preserve source on a review branch. Public release and portfolio listing require a separate owner decision.
